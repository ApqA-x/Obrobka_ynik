# Лабораторна робота 01

**Група:** К-41  
**Студент:** Борисенко Нікіта

## Тема роботи

Визначення кількості секунд у кожному місяці заданого року.

## Мета

Закріпити навички створення програм мовою Python, використання умовних конструкцій, циклів і стандартного модуля `calendar`.

## Виконання роботи

У файлі `seconds_in_months.py` реалізовано програму, яка приймає номер року через консоль і виводить кількість секунд для кожного з дванадцяти місяців. Для визначення кількості днів у місяці застосовано модуль `calendar`, тому програма коректно враховує високосні роки.

## Результат

Для 2025 року програма визначає 2 419 200 секунд у лютому та 2 678 400 секунд у кожному місяці, що має 31 день.

## Висновок

Створено програму для автоматичного обчислення кількості секунд у місяцях довільного року.
