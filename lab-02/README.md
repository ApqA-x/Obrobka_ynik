# Лабораторна робота 02

**Група:** К-41

## Тема роботи

Створення растрового зображення за допомогою графічних примітивів OpenCV.

## Мета

Опанувати створення зображень із використанням бібліотеки OpenCV та її базових графічних примітивів.

## Виконання роботи

У файлі `draw_image.py` реалізовано абстрактну композицію на білому тлі. Чорний трикутний силует сформовано горизонтальними відрізками `cv2.line`. Внутрішні світлі елементи створено за допомогою двох еліпсів `cv2.ellipse`.

## Результат

Створене зображення збережено у файлі `abstract_composition.png`. Код роботи також подано в ноутбуці `PR_2.ipynb`.

## Висновок

Під час роботи застосовано графічні примітиви OpenCV для формування абстрактного растрового зображення.
