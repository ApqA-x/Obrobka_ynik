# Лабораторна робота 03 — сегментація зображень

**Група:** К-41  
**Студент:** Борисенко Нікіта

## Тема роботи

Сегментація кольорових об'єктів та автоматичний підрахунок їх кількості.

## Мета

Опанувати виділення об'єктів на цифровому зображенні за кольоровими ознаками та їх підрахунок засобами OpenCV.

## Виконання роботи

У файлі `segment_objects.py` зображення перетворюється з простору BGR у HSV. Для червоних об'єктів формується маска у двох діапазонах відтінку. Морфологічні операції усувають шум і заповнюють незначні розриви, а зв'язані компоненти дають змогу виділити й підрахувати окремі об'єкти.

## Результат

На обробленому зображенні виділено контури трьох яблук. Підсумковий файл збережено в `results/apples_result.png`, а код також наведено в ноутбуці `PR_3.ipynb`.

## Висновок

Виконано сегментацію кольорових об'єктів, визначено їх контури та автоматично отримано кількість об'єктів на зображенні.
